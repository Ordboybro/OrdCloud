# OrdCloud

Modern desktop file storage built with Python and PySide6.

## Current features

- Dark desktop interface
- Local 5 GB storage
- Folder navigation
- Search
- Upload
- New folder
- Copy and paste
- Rename
- Delete to Recycle Bin
- Back / forward navigation
- Storage usage statistics
- File opening from the explorer

## Tech Stack

- Python 3.11+
- PySide6
- Qt
- psutil
- Pillow
- Send2Trash

## Run

```powershell
python -m venv .venv
.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python main.py
```
