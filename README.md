# OrdFiles

Modern desktop file manager built with Python and PySide6.

## Features

- Modern dark interface
- File browser
- Folder navigation
- Search
- Grid and list views
- Favorites
- Recent files
- Storage statistics
- File operations
- Custom dialogs
- Dark theme

## Tech Stack

- Python
- PySide6
- Qt
- psutil
- Pillow
- Send2Trash
